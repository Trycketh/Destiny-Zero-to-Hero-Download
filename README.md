# Destiny-Zero-to-Hero-Download
Downloadable release for a Destiny 2 Zero to Hero application that allows users to track completed raids and simulate loot drops.

As of the final update, weapons no longer drop for players that have all of the red borders completed. The main purpose of this app is for users that 
have completed weapon patterns to be able to receive weapon drops. There are additional features like random ability unlocks as well.
